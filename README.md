# GalleryTidy information website

Public static website for GalleryTidy on iPhone, iPad and Mac.

- Website and existing app support contract: https://makki93.github.io/GalleryTidy-Info/
- App privacy contract: https://makki93.github.io/GalleryTidy-Info/privacy.html
- Shared app overview: https://makki93.github.io/
- Operator information: https://makki93.github.io/impressum.html
- Contact: bavariantechworks@mailbox.org

The private application repository is not a Pages source. Preserve the two
existing app URLs, including when changing the landing-page layout. GitHub Pages
publishes the root of `main`; `.nojekyll` keeps the site static. No scripts,
external fonts, tracking, form backend or package dependencies are used.

`app-icon.png` is the unchanged 1024px icon shared by the GalleryTidy iOS and Mac
apps. No stock-photo licenses or unrelated application source are included here.

App facts and availability were checked with the GalleryTidy owner on 2026-10-02:
native apps for all three platforms, iOS 27+ closed beta awaiting external review,
no public Mac download. Do not promise an App Store release, public beta link,
guaranteed storage savings or automatic deletion of all low-quality photos.

Before pushing, inspect HTML/CSS changes, validate links and render desktop and
mobile pages. Bump the stylesheet version in both HTML pages when changing styles.
Keep app privacy content aligned with the shipped versions and optional network
features; automatic local analysis is not a claim that all app features are offline.
